tum.ai Makeathon

planetree, a web app for monitoring deforestation from satellite images. Honourable mention at the TUM.ai Makeathon 2024

TUM.ai Makeathon 2024 (April), osapiens challenge. Built in 36 hours by a team of four: Viacheslav Sydora, Danylo Movchan, Bohdan Popov and Petro Laishev. Honourable mention.

Devpost · Code: client, API, ML notebooks

planetree is a web app for monitoring deforestation. Users browse an interactive world map, select a region and click “scan”. The app then processes satellite images of that area and overlays a mask from a segmentation model: forest in green, deforested land in red. Users can also drop pins where they have seen deforestation, which builds up a shared map of hotspots.

  • Frontend: React with styled-components, HERE Maps for the map.
  • Backend: FastAPI with PostgreSQL (SQLAlchemy).
  • Model: a PyTorch computer-vision model, served as a separate microservice so that image processing does not block the main API.
  • Deployment: Docker.
